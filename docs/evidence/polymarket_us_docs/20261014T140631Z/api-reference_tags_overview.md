# Tags API

The Tags API provides access to tags used to categorize and organize events and markets. Tags enable filtering and discovery of related content.

## Endpoints

| Method | Endpoint | Description |
| - | - | - |
| `GET` | `/v2/tags` | Get all tags |
| `GET` | `/v2/tags/{id}` | Get tag by ID |
| `GET` | `/v2/tags/slug/{slug}` | Get tag by slug |
| `GET` | `/v2/tags/featured` | Get featured tags |
